1.  Utilização das API´s do ADN (Ambiente de Dados Nacional) 
 
 
1.1.  Descrição 
 
As APIs descritas neste manual permitem que o contribuinte consulte documentos fiscais de 
serviços em que figure como emitente, tomador ou intermediário. Além disso, está disponível uma 
API para a consulta de eventos vinculados a um documento específico, mediante o uso da chave 
de acesso. 
 
As consultas da API de Distribuição dos Contribuintes agora podem ser realizadas utilizando um 
certificado cujo CNPJ tenha o mesmo CNPJ Raiz do contribuinte para o qual se deseja consultar. No 
caso da consulta por NSU, um novo parâmetro foi adicionado, para que possa ser possível informar 
um CNPJ de consulta diferente do CNPJ do certificado utilizado para estabelecer a conexão (é feita 
a validação do CNPJ Raiz nesse caso, entre o parâmetro informado e o CNPJ do certificado utilizado).  
 
1.1.1.  Métodos 
 
a) GET /DFe/{NSU} 
 
Retorna os documentos fiscais de serviço  correspondente ao NSU informado . O solicitante 
informa um NSU e o sistema nacional retorna o DF-e associado. 
 
 
b) GET – /NFSe/{ChaveAcesso}/Eventos  
 
Retorna os Documentos Fiscais de Serviço do tipo Evento vinculados à chave de acesso 
informada. 
Consulta eventos por chave de acesso. O solicitante informa a chave de acesso de uma NFS -e 
e a API retorna todos os eventos vinculados à chave de acesso de NFS-e informada na consulta.
